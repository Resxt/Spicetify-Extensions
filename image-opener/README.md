# image-opener

![preview](https://raw.githubusercontent.com/Resxt/Spicetify-Extensions/main/image-opener/assets/preview.png)

`image-opener` is a [Spicetify](https://spicetify.app/) extension that allows you to open various images directly in your browser by right clicking the associated element.  

Supported images are:

- Artist avatar
- Artist banner
- Artist gallery
- Track cover
- Album cover
- Playlist cover

## How to use it?

For single picture elements you can right click an associated element (track name, album cover etc.) then click on the "Open cover" button.  

Elements that may contain more than one picture such as artists use an "Open image" sub menu instead.  
Right click an associated element (artist name, artist banner etc.) then simply click on the button you want within that sub menu (includes a button to open all of them in one click!)
